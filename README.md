# VYSION - O Futuro da Vistoria Veicular

Ambiente digital de vistoria automotiva com design minimalista Apple, inteligência artificial integrada para validação fotográfica e interface fluida Opal Glass.

## Estrutura do Fluxo
1. **Boas-vindas Cinematográficas:** Transição personalizada de entrada.
2. **Requisitos do Veículo:** Orientações de iluminação, enquadramento e lente.
3. **Identificação do Veículo:** Formulário de dados simplificado.
4. **Reveal VYSION:** Carregamento elegante com identidade visual.
5. **Câmera Guiada com IA:** Visor imersivo com preview de exemplo, scanner de IA e som de aprovação.
6. **Revisão das Fotos:** Painel de cards com numeração sequencial Montserrat Light e conclusão da vistoria.
